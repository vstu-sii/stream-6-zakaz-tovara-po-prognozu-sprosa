# Глоссарий

| Термин | Определение |
|---|---|
| SKU | Stock Keeping Unit - конкретная товарная позиция с уникальным артикулом. |
| Скоропорт | Товар с коротким сроком годности (<= 7 дней): молочка, хлеб, готовая еда, охлаждёнка. |
| Out-of-stock (OOS) | Товар есть в ассортименте, но отсутствует на полке в момент спроса. |
| Списание | Списание товара по истечении срока годности или порче; прямые потери. |
| Прогноз спроса | Оценка будущего объёма продаж SKU на заданном горизонте. |
| Горизонт прогноза | Период, на который строится прогноз. |
| Сезонность | Регулярное изменение спроса, связанное с временем года, месяцем, днём недели. |
| Промо | Акция, стимулирующая спрос (скидка, «2 по цене 1» и т.д.). |
| Праздник | Календарная дата, вызывающая всплеск спроса (Новый год, 8 марта, Пасха). |
| Страховой запас | Дополнительный объём товара для покрытия случайных колебаний спроса. |
| Уровень сервиса | Целевая вероятность не уйти в OOS (например, 95%). |
| Кратность упаковки | Минимальное количество товара, которое можно заказать (коробка 12 штук). |
| Срок годности | Период, в течение которого товар пригоден к продаже. |
| Черновик заказа | Предварительный заказ, сформированный системой, который человек может изменить. |
| Подтверждение заказа | Действие человека, после которого черновик становится финальным заказом. |
| Правка заказа | Изменение позиции или количества в черновике человеком. |
| Объяснение прогноза | Текстовое пояснение, почему система предлагает такое количество (праздник, промо, тренд). |
| Golden dataset | Эталонный набор примеров «вход - ожидаемый выход» для оценки качества. |
| North Star | Главная метрика продукта, отражающая ценность для пользователя. |
| Mom Test | Методология интервью: спрашиваем про прошлое поведение, не про отношение к идее. |
| Сегмент | Узкая группа пользователей с общими болями и контекстом. |
| Директор магазина у дома | Владелец или управляющий небольшого продуктового магазина (1–3 кассы, 100–400 м²). |
| Категорийный менеджер | Сотрудник, отвечающий за закупки и ассортимент по категории. |
| Поставщик | Компания или ИП, у которого магазин заказывает товар. |
| Заявка | Документ с перечнем SKU и количеством для заказа у поставщика. |
| Тренд | Устойчивое изменение спроса во времени (рост или падение). |
| Квантиль | Значение, ниже которого лежит заданная доля распределения. |
| p95 | 95-й процентиль - значение, ниже которого 95% измерений. |
| Логирование | Запись событий системы для анализа и отладки. |
| Наблюдаемость | Способность понять состояние системы по её логам, метрикам, трейсам. |
